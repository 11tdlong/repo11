Origin

This was started when i wanted to create a smooth movement clock which is currently on the left. Clocks with such movement seems to be so rare, I 've only found them in 2 places (1 is a javascript thing found using Google search named Smooth Seconds Online Clock, other is the clock symbol in iphone). Then I got an idea to have a tool read updates on particular websites, this can be achived using popular web automation tools (cypress, playwright, robotframework, selenium,...) and it needs to be on cloud so we can call it just from the mobiles hence github action, github page with backend provision are built. Next I added some api tests which later became load test demonstration which is also a crucial domain in software testing. And finally so far, I've added muliple choices of reports for automatic regression tests

Description

1. Frameworks and tools
  • AI Copilot (free web version)
  • Html, CSS, Javascript, Github page
  • Nodejs, Express
  • Cypress, Robotframework, Playwright, Selenium java, K6, Cucumber
  • Github action CI
  • Multiple cucumber, Extent, Masterthought, Allure, Robot dashboard report, K6 report templated by Copilot
2. Demonstrations
  • Single File: Start github action workflow to call a cypress script to scrap data on some website, show the output
  • End to End: Call github action workflow to trigger complete test suites, 3 methods supported: robotframework, playwright, selenium
  • API Check: Run an api test directly from backend, no CI workflow
  • Load Test: Call github action workflow to trigger a loadtest. This and the 3 require a stock code in VN market
